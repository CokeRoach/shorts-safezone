Where the zones come from

PlatformClear area on 1080 x 1920Source

YouTube and TikTok zones are measured pixel by pixel from the official templates. Reels uses the percentages in Meta's ad guide. All three platforms publish these for ads; organic videos get the same buttons, so the zones are a good guide, but not a promise. TikTok's zone shrinks with long captions. Checked 2026-11-24.

Also a Python tool: pip install shorts-safezone. Source and issues: github.com/CokeRoach/shorts-safezone
