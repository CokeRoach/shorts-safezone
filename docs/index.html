Where the zones come from

YouTube and TikTok zones are measured pixel by pixel from the official templates. Reels uses the percentages in Meta's ad guide.

All three platforms publish these for ads. Organic videos get the same buttons, so the zones are a good guide but not a promise. TikTok's zone shrinks with a long caption. Checked 2026-11-24.

Also a Python tool for scripts and render checks: pip install shorts-safezone. Source and issues on GitHub.
